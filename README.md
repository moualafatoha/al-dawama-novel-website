🌀 موقع رواية الدوّامة
==========================

موقع رسمي جميل واحترافي لرواية الدوّامة للكاتبة نبال بورحماني

## 📖 عن الموقع

موقع تفاعلي متخصص لرواية **الدوّامة** - رواية درما نفسية سوداوية من تأليف **نبال مروة بورحماني**.

### المميزات 🎨

✨ **التصميم**
- واجهة أنيقة بألوان أزرق داكن وفاتح مع رمادي
- تصميم مريح للعين وسهل التصفح
- رموز زخرفية تعكس موضوع الدوّامة
- تأثيرات زجاجية (Glassmorphism) حديثة

📱 **الاستجابة**
- متوافق تماماً مع جميع الأجهزة
- تجربة سلسة على الهاتف والتابلت والحاسوب

🛒 **نظام الطلبات**
- نموذج طلب سهل وواضح
- إرسال مباشر للبريد الإلكتروني
- تفاصيل شاملة للتوصيل

📧 **التواصل**
- ربط مباشر مع البريد الإلكتروني
- روابط لوسائل التواصل الاجتماعي
- نموذج تعليقات للقراء


## 🚀 كيفية الاستخدام

### التثبيت المحلي

1. **استنساخ المستودع:**
```bash
git clone https://github.com/moualafatoha/al-dawama-novel-website.git
cd al-dawama-novel-website
```

2. **إضافة الصور:**
   - أنشئ مجلد `images` في جذر المشروع
   - أضف الصور التالية:
     - `dawama-cover.jpg` - غلاف الرواية (حجم مناسب: 250x350px)
     - `dawama-3d.jpg` - الغلاف ثلاثي الأبعاد (حجم مناسب: 390x230px)
     - `dawama-full.jpg` - صورة كاملة (حجم مناسب: 430x400px)
     - `author.jpg` - صورة الكاتبة (حجم مناسب: 140x140px)

3. **فتح الموقع:**
   - افتح ملف `index.html` مباشرة في المتصفح
   - أو استخدم خادم محلي مثل Live Server

### نشر على الويب

#### خيار 1: GitHub Pages (مجاني)
```bash
git push origin main
```
ثم فعّل GitHub Pages من إعدادات المستودع (Settings > Pages)
الموقع سيكون متاحاً على: `https://moualafatoha.github.io/al-dawama-novel-website`

#### خيار 2: Netlify
1. انتقل إلى [netlify.com](https://netlify.com)
2. اختر "Connect to Git"
3. اختر هذا المستودع
4. سيتم نشر الموقع تلقائياً

#### خيار 3: Vercel
1. انتقل إلى [vercel.com](https://vercel.com)
2. اختر "Import Project"
3. اختر هذا المستودع
4. سيتم النشر بسهولة

## 🔧 التعديلات المستقبلية

يمكنك تعديل:

### تغيير الألوان:
عدّل متغيرات CSS في `styles.css`:
```css
:root {
  --navy: #0b1f3a;
  --deep-blue: #12345b;
  /* وهكذا... */
}
```

### تحديث البيانات:
- عدّل النصوص مباشرة في `index.html`
- أضف صور جديدة في مجلد `images`
- حدّث البريد الإلكتروني حسب الحاجة

### إضافة صفحات جديدة:
1. أنشئ ملف HTML جديد (مثل `about.html`)
2. استخدم نفس `styles.css` و `script.js`
3. أضف رابط في Navigation Bar

## 📱 الميزات التفاعلية

### 1. نموذج الطلب
- يجمع بيانات العميل (الاسم، الولاية، البلدية، الهاتف، عدد النسخ)
- يرسل الطلب مباشرة عبر البريد الإلكتروني
- يعرض رسالة تأكيد

### 2. سلة الشراء
- زر سريع "اطلب نسختك" ينقلك لنموذج الطلب
- يسهل عملية الشراء

### 3. نموذج التعليقات
- يسمح للقراء بترك تعليقاتهم
- تُرسل مباشرة للبريد الإلكتروني

### 4. الروابط الاجتماعية
- روابط مباشرة للإنستغرام والتيك توك
- سهل التحديث والصيانة
